# Smart Pantry Manager

A Java Android app that reduces food waste by tracking the ingredients
you already have and suggesting only the recipes you can make right now.

## Database choice
SQLite (SQLiteOpenHelper) - runs locally on-device, no network or
backend needed, and persists data between sessions.
(Justification to be expanded.)

## Setup / Run
1. Clone the repository
2. Open the project in Android Studio
3. Let Gradle sync
4. Run on an emulator or physical device (min SDK 24)
